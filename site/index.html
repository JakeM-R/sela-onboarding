How it's built

Feed

Vast.ai's public bundles search, no key. Hosts list the same machine several times as 1, 2, 4 and 8-GPU bundles, so each machine counts once at its cheapest per-GPU price. Prices include the default disk.

Two baselines

Cross-sectional, live now: Thunder's percentile in today's distribution. Time series, building: each GPU's median against its own history. A move is flagged when it's more than 2 standard deviations from that GPU's usual 6-hour change, once 8 snapshots exist.

Limits

One marketplace. Vast hosts vary (community machines, unverified hosts, variable reliability), which is why datacenter-only medians are shown alongside. "Rented" is the share of listed hosts not rentable right now. Thunder prices are hardcoded with an as-of date.

A GitHub Action runs fetch.py every 6 hours, writes the snapshot and appends to history.json. No backend. Source on GitHub.
