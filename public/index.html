From application to day one

Paste a job description and one candidate's CV and answers. The agent builds a rubric on Sela's three hiring values plus the role's must-haves, scores the candidate with the CV line behind every score, writes the interview questions, drafts the reply, and on hire writes the onboarding pack.

Built by Jake Makking-Robinson for Sela's strategy & ops role. A working draft, not a Sela product.
Seconds per candidate, against an estimated 20–30 minutes to read, score and reply by hand. The agent drafts; a person makes every decision.

        How it works: the three values axes and their 1/3/5 anchors are fixed and written by hand. The model only adds the role's must-haves, each quoting its job-description line. Every evidence quote is checked against the pasted text; any quote that can't be found is flagged in red. The advance / decline suggestion is a fixed rule on the scores (any must-have at 2 or below suggests decline), not a model judgement.
        
    
        Demo candidates and the sample posting are synthetic. Model: Claude, called server-side so no key reaches the browser. Inputs are not stored; identical inputs are cached at the edge for a week.
